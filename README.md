# 🛡️ CSEH Cybersecurity & Networking Workshop #1

> **Interactive Cybersecurity & Networking Workshop** — Covering Cyber Fundamentals, Rules of Engagement, Linux & Kali VM Architecture, Wi-Fi Analysis, Live Defense Demos, Mini CTFs, and Cyber Arcades.

---

## 🎯 Workshop Overview

This interactive workshop web platform was created for the **CSEH Club Cybersecurity Workshop #1** to provide engineering students with a hands-on, engaging journey through cybersecurity, network architecture, penetration testing methodologies, and defensive security.

---

## 📖 Modules & Curriculum

1. **🛡️ 1. Intro, Vulnerabilities & Exploits**
   - CIA Triad (Confidentiality, Integrity, Availability)
   - Zero-Days, CVEs, CWEs & Exploit mechanics
   - Threat actor profiling and threat models

2. **⚖️ 2. Rules of Engagement (RoE) & Ethics**
   - Legal boundaries, white-hat ethics & authorized testing
   - Scope definition and reporting guidelines

3. **💻 3. OS, Kernel & Kali Linux VM Architecture**
   - Kernel space vs User space
   - Setting up Kali Linux in virtualized environments
   - Essential shell utilities & package management

4. **🌐 4. Linux, MAC, IP & Networks**
   - OSI & TCP/IP models, Packet routing
   - MAC address spoofing, IP addressing & CIDR subnetting
   - Active network reconnaissance (`nmap`, `ping`, `traceroute`)

5. **📡 5. Wi-Fi Modes & Channels**
   - Managed vs Monitor mode, 802.11 frame types
   - 2.4 GHz vs 5 GHz channel overlaps
   - WPA2 4-Way Handshake & WPA3 SAE (Dragonfly)

6. **🔬 6. Controlled Wi-Fi Lab & Analysis**
   - Capturing beacon and handshake frames in controlled labs
   - Deauthentication mechanisms and packet dissection

7. **🏰 7. Defense & Security Upgrades**
   - WPA3 migration, Protected Management Frames (802.11w)
   - Network segmentation (VLANs), IDS/IPS, and Zero Trust

8. **🎌 8. Anime Cyber Theater**
   - Visualized storytelling of cyber battles featuring Rayleigh, Kakashi, and Kisuke Urahara

9. **🚩 9. Mini CTF Challenges**
   - Interactive capture-the-flag riddles with real-time flag validation

10. **🧠 10. Cyber Security Quiz**
    - Live knowledge evaluation with immediate feedback and scoring

11. **🎮 11. Cyber Arcade & Bio-Defrag**
    - Interactive mini-games & cyber break activities

12. **🚀 12. Wrap-up & Careers**
    - Roadmaps into SOC analysis, PenTesting, Bug Bounty & Certifications (CEH, OSCP, CompTIA Security+)

## 🚀 Quickstart & Local Development

### 1. Clone the repository:
```bash
git clone https://github.com/BogguAjayKumar/CSEH-workshop1.git
cd CSEH-workshop1
```

### 2. Install dependencies:
```bash
npm install
```

### 3. Start the development server:
```bash
npm run dev
```

The application will be accessible at `http://localhost:5173/`.

### 4. Build for production:
```bash
npm run build
```
